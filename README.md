# Flight Fare Prediction Using Machine Learning

## Overview
This project predicts airline ticket prices using Machine Learning algorithms. The model analyzes flight details such as airline, source, destination, duration, total stops, departure time, and arrival time to estimate airfare.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow
1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Correlation Analysis
6. Model Building and Evaluation
7. Flight Fare Prediction
